# Audio attribution and provenance

The OGG files in `kenney_impact` and `kenney_rpg` are unmodified selections from Kenney's CC0 [Impact Sounds](https://kenney.nl/assets/impact-sounds) and [RPG Audio](https://kenney.nl/assets/rpg-audio) packs. Original license files are included in each directory. Files were obtained from the [assets-sfx-combat mirror](https://github.com/GeorgeQLe/assets-sfx-combat), which includes the original per-pack license files. Kenney attribution is optional under CC0.

The feedback system also includes synthesized fallback cues for unavailable resources; automatic tests check resource identity and event dispatch, not audible quality.
