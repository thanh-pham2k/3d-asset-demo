# Progression Design

## P1 Progression Loop (Implemented)
1. Player starts with initial unlocked `EMPTY` plots and `LOCKED` plots visible in the farm.
2. Player plants carrots (`-5 xu`), waits for growth, and harvests (`+2 carrots`).
3. Player delivers `4 carrots` on `OrderBoard` to earn `+60 xu`.
4. Player spends `120 xu` via `FarmUpgrade` to unlock an additional `FarmPlot` (`LOCKED` -> `EMPTY`).

## P2–P6 Progression (Playable Alpha)
- **P2:** Unlockable crops (5–8 types), 6–12 plots, and `Inventory` capacity upgrades, with no-dead-end recovery.
- **P3:** Unified `ProgressionSystem` (`XP`, `Level`, milestones) unlocking crops, orders, and features.
- **P4–P5:** Production recipes, station queue slots, Hu Tieu dishes, and kitchen/table upgrades.
- **P6:** Staff hiring and automation speed/capacity upgrades.
