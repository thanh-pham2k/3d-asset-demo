# Progression — VERY MVP

## Stage 1 Progression Loop
1. Player starts with initial unlocked `EMPTY` plots and at least one `LOCKED` plot visible in the farm.
2. Player plants carrots (`-5 xu`), waits for real-time growth, and harvests (`+2 carrots`).
3. Player delivers `4 carrots` on the `OrderBoard` to earn `+60 xu`.
4. Player spends `120 xu` via `FarmUpgrade` to unlock an additional `FarmPlot` (`LOCKED` -> `EMPTY`), increasing production capacity.
