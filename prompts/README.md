# AI Prompts Directory

This folder stores **HOW TO EXECUTE** instructions for AI Agents.
- `templates/` — reusable prompt templates for implementation, asset generation, and code review.
- `features/` — feature-specific execution prompts keyed by Feature ID (`FARM-001`, `FARM-002`, `ECON-001`, `ECON-002`, `ORDER-001`, `PROG-001`, `SAVE-001`).
- `archive/` — retired prompts kept for reference only.

Before implementing any feature, read `AGENTS.md`, the corresponding `docs/` spec, and the feature prompt in `prompts/features/`.
